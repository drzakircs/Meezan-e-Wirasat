# Meezan e Wirasat | میزانِ وراثت | ميزان المواريث

An interactive Islamic inheritance guide and calculator covering selected rules of the four Sunni schools of jurisprudence.

اسلامی وراثت کی رہنمائی اور حساب کے لیے ایک تعاملی ایپلی کیشن، جس میں چاروں سنی فقہی مذاہب کے منتخب قواعد شامل ہیں۔

دليل تفاعلي وحاسبة للمواريث الإسلامية يشملان أحكاماً مختارة من المذاهب السنية الأربعة.

## English

### Key Features

- **Three-language interface:** Switch between English, Urdu and Arabic across the guide, calculator, results and generated reports. Changing the language preserves the current calculation.
- **Language-appropriate typography:** Urdu uses **Noto Nastaliq Urdu**; Arabic uses **Noto Naskh Arabic**. Both support right-to-left layouts, with fonts embedded for offline use and report printing.
- **Step-by-step calculator:** A five-stage workflow guides users through case details, estate preparation, surviving relatives, input review and explained results.
- **Four Sunni schools:** Select **Hanafi, Maliki, Shafi‘i or Hanbali**, with comparisons explaining important differences and applicable school positions.
- **21 relative categories:** Enter spouses, children, parents, a son’s children, the immediate paternal grandfather and grandmothers, full and half-siblings, brothers’ sons and paternal uncles within the supported categories.
- **Estate preparation:** Record assets belonging to the deceased, established funeral expenses, debts and valid bequests to determine the net distributable estate.
- **Explained inheritance shares:** View initial prescribed shares, final group shares, each person’s entitlement, amounts and reasons for exclusions. Supported calculations include residue, **‘awl**, **radd** and selected special combinations.
- **Exact fractions and reconciled amounts:** Calculations retain exact fractions and reconcile currency rounding so allocated amounts match the net estate. PKR, USD, GBP and EUR labels are available; no currency conversion is performed.
- **Searchable rule library:** Explore **16 main sections and four additional special-case chapters**, with **35 source links** to Quranic passages, Hadith and jurisprudential references.
- **12 interactive worked examples:** Change the school and estate amount for defined family scenarios and compare the resulting distributions.
- **Visual explanations:** Distribution charts, share tables and school comparisons make the results easier to understand on desktop and mobile screens.
- **Reports in the selected language:** Download self-contained **UTF-8 HTML calculation reports** and the rulebook. Calculation reports include deductions, shares, individual amounts and explanations, with print styles, embedded fonts and right-to-left support where appropriate.
- **Offline use:** The standalone HTML application includes its scripts, translations and fonts. The guide, calculator and examples work offline; opening external source websites requires an internet connection.
- **Local calculation inputs:** Calculator inputs remain in page memory and are cleared on refresh. The application does not send calculator entries to a server. Only the language preference is stored in browser local storage.

### Calculator Scope

The calculator supports the listed relative categories and implemented school positions. It flags cases requiring further determination, including additional generations or distant kindred, pregnancy, missing heirs, disputed eligibility, uncertain death order and certain disputed school positions. Applicable national succession law may require separate consideration.

### Getting Started

Open the application's `dist/index.html` file in a modern browser, choose a language, and select **Calculator**. Follow the five stages and use **Download calculation** or **Print result** to save the result.

### الميزات الرئيسية

- **واجهة بثلاث لغات:** التبديل بين الإنجليزية والأردية والعربية في الدليل والحاسبة والنتائج والتقارير. يبقى الحساب الحالي محفوظاً عند تغيير اللغة.
- **خطوط مناسبة لكل لغة:** يُستخدم **Noto Nastaliq Urdu** للأردية و**Noto Naskh Arabic** للعربية، مع ترتيب من اليمين إلى اليسار وتضمين الخطوط للاستخدام دون اتصال وطباعة التقارير.
- **حاسبة خطوة بخطوة:** خمس مراحل تشمل معلومات المسألة، وإعداد التركة، والورثة الأحياء، ومراجعة البيانات، والنتائج الموضحة.
- **المذاهب السنية الأربعة:** اختيار المذهب **الحنفي أو المالكي أو الشافعي أو الحنبلي**، مع مقارنات تشرح أهم الاختلافات والآراء المطبقة.
- **21 فئة من الأقارب:** إدخال الزوج أو الزوجات، والأولاد، والوالدين، وأولاد الابن، وأب الأب، وأم الأب وأم الأم، والإخوة والأخوات الأشقاء ولأب ولأم، وأبناء الإخوة والأعمام، ضمن الفئات المدعومة.
- **إعداد صافي التركة:** تسجيل أصول المتوفى ونفقات التجهيز والدفن الثابتة والديون والوصايا الصحيحة لتحديد صافي التركة القابل للتوزيع.
- **شرح الأنصبة وأسبابها:** عرض الفروض الأصلية وأنصبة المجموعات النهائية واستحقاق كل فرد والمبالغ وأسباب الحجب. تشمل الحسابات المدعومة الباقي و**العَول والرد** ومسائل خاصة مختارة.
- **كسور دقيقة ومبالغ متطابقة:** يحتفظ الحساب بالكسور الدقيقة، مع تسوية التقريب في الوحدات النقدية الصغيرة ليطابق إجمالي التوزيع صافي التركة. تتوفر تسميات PKR وUSD وGBP وEUR، دون تحويل أسعار العملات.
- **مكتبة أحكام قابلة للبحث:** استعراض **16 قسماً رئيسياً وأربعة فصول إضافية للمسائل الخاصة**، مع **35 رابطاً للمصادر** من القرآن والحديث والمراجع الفقهية.
- **12 مثالاً تفاعلياً محلولاً:** تغيير المذهب ومبلغ التركة في مسائل أسرية محددة، ومقارنة نتائج التوزيع.
- **توضيحات بصرية:** مخططات التوزيع وجداول الأنصبة ومقارنات المذاهب تساعد على فهم النتائج عبر الحاسوب والهاتف.
- **تقارير باللغة المختارة:** تنزيل **تقارير حساب بصيغة HTML وترميز UTF-8** وكتاب الأحكام. تشمل تقارير الحساب الخصومات والأنصبة ومبالغ الأفراد والتفسيرات، مع تنسيق للطباعة وخطوط مضمنة واتجاه كتابة مناسب للغة.
- **العمل دون اتصال:** يتضمن ملف HTML المستقل الشيفرات والترجمات والخطوط. يعمل الدليل والحاسبة والأمثلة دون اتصال؛ وتحتاج زيارة مواقع المصادر الخارجية إلى الإنترنت.
- **بقاء بيانات الحساب محلياً:** تبقى مدخلات الحاسبة في ذاكرة الصفحة وتُمسح عند إعادة تحميلها، ولا يرسلها التطبيق إلى خادم. يُحفظ تفضيل اللغة فقط في التخزين المحلي للمتصفح.

### نطاق الحاسبة

تغطي الحاسبة فئات الأقارب المذكورة والآراء الفقهية المنفذة. وتنبّه إلى المسائل التي تحتاج إلى تحديد إضافي، مثل الأجيال الأعلى أو ذوي الأرحام، والحمل، والورثة المفقودين، والأهلية المتنازع عليها، وجهل ترتيب الوفاة، وبعض الآراء الفقهية المختلف فيها. وقد تحتاج قوانين الميراث المحلية إلى دراسة مستقلة.

### بدء الاستخدام

افتح ملف التطبيق `dist/index.html` في متصفح حديث، ثم اختر اللغة وانتقل إلى **الحاسبة**. اتبع المراحل الخمس، واستخدم خيار تنزيل تقرير الحساب أو طباعة النتيجة لحفظها.
